# WEB9000 — one-screen project status

**2026-11-19 · `main` is the active development branch · former PR #1 merged by fast-forward with owner approval**

**Start here when resuming work.** For detailed tasks and links see [OPEN-ISSUES.md](./OPEN-ISSUES.md); for discovered technical/design mismatches see [BACKEND-AUDIT.md](./BACKEND-AUDIT.md); all exact owner constraints are in [PRODUCT-REQUIREMENTS.md](./PRODUCT-REQUIREMENTS.md) and dated [CHAT-DECISIONS.md](./CHAT-DECISIONS.md). **AGENTS.md is mandatory for new instances.**

**2026-11-19 UI fix:** Debug is now opened only from the top-right header, with post/comment dump controls **inside** the pop-up. A bounded live WebSocket trace begins before the console opens, and recent packets persist on same-tab reload; pause affects display only. For image previews, a visible **Enable images · HOST** button or an explicit **Load image from HOST** click approves the proposed gateway, making signed demo thumbnails available while avoiding silent third-party media downloads. **Superseded media-activation requirement:** the owner rejected imageboard buttons that require readers to enable the first-party site gateway. Same-origin media advertised by the current site's own `demo.json` now loads image thumbnails automatically (including unfamiliar signed authors). Unrelated external media hosts remain opt-in, and neither IPFS mirroring nor third-party contact is activated. Clean-browser Chromium covers automatic image display on first load and reload.

**Compact spider UI (2026-11-19):** the oversized per-article suitability section is replaced with a small draggable five-axis popup opened from a 🕸 button beside the numeric vote score. Live plain-language axis explanations, pointer/keyboard controls, signed Submit and a report-menu-only civic censorship-pressure alert are included; the civic flag is an independent signed label and never changes the post's age scores. No additional body/scroll height until opened. Reader age thresholds remain voluntary.

**Gray spider background (2026-11-19 owner correction):** Default gray reference now derives the per-axis median of **all other signers' independently verified signed ratings observed by this browser**, rather than only an explicitly trusted subgroup. The pink editable shape excludes the same author's ratings from the gray median; the legend displays observed other-signer count separately from filter-qualified raters. This is only a discovery/visual layer and **does not grant any extra author permission to blur/hide**. Future group-federation scoping needs independently verified group membership/delegation and opt-in trust policies; absence of records remains subject to peer omissions.

**Owner-corrected multidimensional review (2026-11-19):** groups rate **content independently**, not each other's decisions. New signed age/suitability tiers, four-axis post radar charts, a separate high-public-interest/censorship-pressure alert, signed group distrust and reviewer conduct evidence, readable reviewer audit/profile UI and self-candidacy with quorum appointment/removal. Reader-local versioned 2/5/2 media blur/hide/credible-dissent thresholds are **OFF by default**, not binding universal moderation. Age/legal-concern labels are opinions; no outside group can globally ban posts. See [COMPOSABLE-MODERATION.md](./COMPOSABLE-MODERATION.md) for unimplemented accuracy scoring, calibrated suggestions, appeal and anti-Sybil safeguards.

**Working prototype:** seven-column classic WEB9000 board, signed posts/comments/metadata, corrections/withdrawals, group charter/quorum votes and proof export, local author friend/foe, raw WebSocket/record debug, actual Helia/OrbitDB peers, volunteered IPFS media hosting with images ≤256 KiB and audio/video ≤10 MiB, explicit media-provider claims and manually approved backup gateways. Browser does **NOT** automatically pin/serve file bytes. Qualified index exists but admits **no verified users**.

**Concrete fix in current audit:** `loadSuggestions` no longer silently authorizes the suggested media gateway; the browser requires an explicit Connect click. Older persisted gateway URLs are preserved as **pending review** until reapproved (even previously manually approved URLs require one confirmation because old versions did not record consent distinctly). Chromium tests exercise both flows. Confirm CI and deployment state on the final pushed commit before declaring release.

**Nostr research:** [NOSTR-RESEARCH.md](./NOSTR-RESEARCH.md). Best concepts to adapt are NIP-77 Negentropy, NIP-65 outbox discovery, NIP-32/56 signed moderation evidence, NIP-46 remote signer, and Blossom's verified/replaceable media hosts. NIP-29's relay-administered groups violate WEB9000's resistance to administrator capture as the default governance primitive.

**Don't regress:** no namespace owner, no global deletion, no required credential for signature-valid raw publishing, no forced media mirroring, no public social graph without consent, no fabricated karma, no silent 'latest' authority or arbitrarily simplified seven-column UI.
