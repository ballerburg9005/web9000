Local, disconnected Alternate dashboard
WEB9000 experimental board. The default view excludes unverified authors. There is no live Stake4Karma qualification service yet: to inspect actual test posts from other identities, deliberately enable Show unstaked / unverified. No website or namespace owner can invalidate the original signed records.
Choose independent peers

Peer listings are suggestions, never a mandatory registry or authority. Each peer may refuse to replicate content; anybody can run a different one. Browser WebSocket connections expose your IP to the chosen operator.

Media uploads are explicit and size-limited. Other people’s images are never fetched automatically merely because they posted a CID.

Local-only posts queue until a willing peer acknowledges them. If an endpoint is offline, export and share signed records or try another peer.
Numeric karma test provider

Simulation only. Assign a numerical score to a public signing identity to prototype how qualified feeds might behave. This does not represent locked coins, independently earned reputation, or an on-chain verification. This browser stores its own simulated numbers.

Score 10+ passes the local simulated feed. The shared qualified peer remains independently verified and does not accept these numbers. Do not mistake this for Sybil protection.
Make a post

File uploads use the optional selected media peer, not a centralized website database. Images cannot be published as arbitrary inline code. If no upload peer is configured, publishing image files is refused with an explanation.
