Signed source-network classifications (optional)

Each independent peer can observe an incoming socket IP and classify its network using its own signed, updateable country/ASN/VPN list. To use an observer's report for local sync quotas, pin its identity explicitly: one line with a peer WebSocket URL, a space, and its ed25519: key. The list is verified and updates automatically over the same peer connection. No raw IP is included in received reports. A relay's observed IP is not necessarily the original author's. Unpinned or unverifiable observations use the limited unknown tier; no classification can invalidate a signed record or ban authors network-wide.
